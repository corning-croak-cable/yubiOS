## Honest caveats

1. **Binarization is heuristic** -- 9 regex patterns per primitive, no LLM judgment. A stricter pass (e.g., LLM-as-judge on file content) could surface sub-primitives not caught here.
2. **Chordal residual = 0.0** for all lenses (placeholder; full pipeline would compute the actual Fibonacci-lattice residual after a curve fit, as in `hyperspherical-harmonic-curve`).
3. **Verdict rule** is intentionally generous: k=9 -> YES, 4 <= k < 9 -> PARTIAL, k < 4 -> NO. A stricter gate (k >= 7 for YES) would re-classify more lenses.
4. **Score is round(50 * k / 9)**, not a learned rank. The full guided-curve-ideate cycle-34 ranks by analytical criteria; this is a first cut.

## Lens format (v1.1.0)

Each lens is a CONCRETE EXPERIMENT with:

- **lens**: ID (L147..L538 across 392 files)
- **file**: path relative to repo root
- **hypothesis**: a testable claim about this file
- **method**: how the test runs (the 9-D primitive binarization + chordal distance)
- **parameters**: `{basis, d, seed}`
- **delta**: `{k, missing_primitives, chordal_resid}`
- **verdict**: YES / PARTIAL / NO (three-valued, never yes/no binary)
- **score**: 0-50 rank
- **caveat**: what the experiment did NOT measure

The lens is the experiment; the file patch is a reference to the lens, not inlined JSON.
