# yubiOS logo explorations

These are 2048 x 2048 PNG concept marks generated from the project's existing
glitch-flower language and the maintainer-supplied visual references.

| File | Direction |
|---|---|
| `yubios-linked-bloom-2048.png` | Bloom, keyhole, and linked trust ring. |
| `yubios-owner-orbit-2048.png` | Three interlocking petals around an owner-held core. |
| `yubios-trust-tree-2048.png` | Root-to-bloom convergence for firmware, OS, and owner identity. |

These files do not replace the canonical [`../logo.png`](../logo.png). Before
adopting one as a production mark, vectorize and simplify it, test it in
monochrome and at 16-32 px, run accessibility checks, and complete the name,
logo, and trademark review tracked in [`../../PR.md`](../../PR.md).

The full prompts and reference roles are recorded in
[`../visual-generation-prompts-2026-07-22.md`](../visual-generation-prompts-2026-07-22.md).
