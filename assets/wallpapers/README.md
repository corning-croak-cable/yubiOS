# yubiOS wallpapers

These text-free 3840 x 2160 JPEG wallpapers extend the project's dark-first,
hot-pink, violet, cyan, and acid-green visual language. They reserve calmer
areas for GNOME shell chrome and desktop content.

| File | Direction |
|---|---|
| `yubios-aurora-ridge-4k.jpg` | Quiet mountain ridge beneath a luminous trust halo. |
| `yubios-owner-rings-4k.jpg` | Concentric glassy waves around an owner-held core. |
| `yubios-living-root-4k.jpg` | A bloom dissolving into circuit-like roots and rivers. |
| `yubios-nocturne-bands-4k.jpg` | Dark architectural bands with sparse pigment pulses. |
