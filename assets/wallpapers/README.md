# yubiOS wallpapers

These text-free 3840 x 2160 JPEG wallpapers extend the project's hot-pink,
violet, cyan, and acid-green visual language. Each original dark-first
composition is preserved alongside purpose-built light- and dark-mode variants,
with calmer areas reserved for GNOME shell chrome and desktop content.

| Original | Light mode | Dark mode | Direction |
|---|---|---|---|
| `yubios-aurora-ridge-4k.jpg` | `yubios-aurora-ridge-4k-light.jpg` | `yubios-aurora-ridge-4k-dark.jpg` | Quiet mountain ridge beneath a luminous trust halo. |
| `yubios-owner-rings-4k.jpg` | `yubios-owner-rings-4k-light.jpg` | `yubios-owner-rings-4k-dark.jpg` | Concentric glassy waves around an owner-held core. |
| `yubios-living-root-4k.jpg` | `yubios-living-root-4k-light.jpg` | `yubios-living-root-4k-dark.jpg` | A bloom dissolving into circuit-like roots and rivers. |
| `yubios-nocturne-bands-4k.jpg` | `yubios-nocturne-bands-4k-light.jpg` | `yubios-nocturne-bands-4k-dark.jpg` | Architectural bands with sparse pigment pulses. |

The light variants use pale, low-glare fields behind dark shell chrome. The
dark variants deepen the original nocturnal treatment while preserving
midtones and highlight detail behind light shell chrome.
